# Проект Client_operation

## Описание:

Проект Client_operation - это виджет банковских операций клиента на Python. Позволяет замаскировать
номер карты и счета. Так же производит сортировку введенных словарей по заданному параметру и дате.

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:pannikolaserg-prog/Client_operation.git
```

## Использование:

1. Откройте виджет в вашем PyCharm.
2. Откройте модуль widget.py и введите данные карты и счета для функции mask_account_card, 
а так же дату в формате "2023-12-25T10:30:00" для функции get_date.
3. Откройте модуль processing.py и введите список словарей и ключ для сортировки для функции filter_by_state.
4. Так же возможна сортировка по дате для функции sort_by_date.
5. Откройте модуль generators и введите список словарей, отображающих транзакции.
6. Введите диапазон номеров карт для функции card_number_generator
7. Функция load_transactions в модуле utils обрабатывает список транзакций.
8. Функция get_amount_in_rub позволяет конвертировать из USD и EUR в рубли.
9. Функция read_csv_exel производит чтение данных из файлов типа .csv и .xls (таблицы).

## Тестирование:
1. В структуре проекта созданы четыре модуля для тестирования.
2. В модуле test_mask тестируется работа функции маскировки карты и номера счета.
3. В модуле test_widget осуществляется проверка работы функции маскировки карт и счетов,
а так же, преобразования даты.
4. В модуле test_processing тестируется работа функции фильтрации словарей по ключу и по дате.
5. В модуле test_generators тестируется работа функции фильтрации по заданной валюте, корректность
описания каждой транзакции, а так же правильность отображения номеров карт в заданном диапазоне.
6. В модуле test_utils тестируется работа функции обработки транзакций.
7. В модуле test_external_api тестируется работа функции c API ключом.
8. В модуле test_read_csv_exel тестируется работа функции c табличными данными.
